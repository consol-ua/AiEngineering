Як підключити модель і не чекати вічно

Після цього розділу ви зможете

Обмежити час очікування й перевірити, коли варто повторити невдалий виклик.

Зовнішня модель отримує запит через мережу, тому може відповідати повільно або бути недоступною. Олена натиснула «Запитати» й чекає інструкцію VPN. Програма має або відповісти, або завершити очікування зрозумілим повідомленням, а не крутити індикатор нескінченно.

Вам достатньо базового Python: функцій, списків, словників та винятків. Працюємо над одним помічником для інструкцій команди. Спочатку прочитайте приклад, потім запустіть маленький код, після цього виконайте власне завдання. Незрозуміле слово шукайте на сторінці «Нові слова простими словами».

Як це працює на прикладі

Тайм-аут — максимальний час однієї спроби. Повтор доречний для тимчасового перевантаження, але не виправить неправильний ключ доступу. Обмежте кількість спроб і додайте коротку паузу. Також контролюйте загальний час: дві спроби з паузою тривають довше за одну.

async дозволяє іншим запитам працювати, поки цей чекає мережу. Саму модель він не прискорює. Для практики зробимо швидку, повільну й помилкову підміну сервісу. Це допоможе навчитися обробляти збої без оплати реальних викликів.

Розрахунок крок за кроком

Загальний час ≈ час усіх спроб + паузи + інші витрати.

Дві спроби по 2 секунди й пауза 0,2 секунди вже дають близько 4,2 секунди. Межа однієї спроби не є межею всього запиту. Короткі значення в нашому коді потрібні лише для швидких навчальних тестів.

Спробуйте змінити одне число

Повторіть розрахунок на аркуші або в Python. Спочатку передбачте результат, потім перевірте. Важливо розуміти, що саме вимірює число: схожість, правильність, пам’ять чи час. Не всі ці показники можна порівнювати між собою.

Корисні звички та їхня ціна

Різні причини

Перевантаження можна повторити, неправильні дані слід виправити.

Межа паралельності

Semaphore — лічильник дозволених одночасних робіт. Почніть, наприклад, із 5.

Ключ поза кодом

API-ключ — секрет доступу до сервісу. Читайте його зі змінної середовища й не друкуйте.

У кожної зручності є ціна. Додатковий пошук займає час, збереження даних потребує місця, перевірки додають код. Оберіть одну пораду й поясніть, від якої конкретної помилки вона захищає.

Код: запускаємо та розбираємо

  1. Знайдіть generate(): він викликає передану функцію.
  2. asyncio.wait_for() обмежує одну спробу.
  3. TransientError позначає тимчасовий збій.
  4. Перевірте швидкий результат, повільний виклик і постійну помилку окремо.
Завантажити 05.py — код і перевірки ↓

Збережіть файл у новій папці. Приклад працює на Python 3.12+ зі стандартною бібліотекою, без платних сервісів. Нижче його основна частина; спочатку розберемо, що роблять функції.

"""Run: python 05.py. Bounded attempt retries with a fake async provider.
A real HTTP adapter must also enforce the overall request deadline.
"""
import asyncio
import unittest

class TransientError(Exception):
    pass

async def generate(provider, question, attempts=2, timeout=0.1, backoff=0.01):
    if attempts < 1 or timeout <= 0 or backoff < 0:
        raise ValueError('Invalid retry policy')
    for attempt in range(attempts):
        try:
            return await asyncio.wait_for(provider(question), timeout)
        except (TransientError, asyncio.TimeoutError) as error:
            if attempt + 1 == attempts:
                raise TransientError('Provider unavailable') from error
            await asyncio.sleep(backoff * 2**attempt)

Що тут відбувається

  • fake тут асинхронна функція, а не мережевий сервіс.
  • await дозволяє іншим роботам виконуватися під час очікування.
  • Helper обмежує кожну спробу. Загальну межу HTTP-запиту додайте окремо.

Перевірки та обробка помилок

У завантаженому файлі вже є перевірки. Виконайте python 05.py з його папки. Наприкінці має бути OK. Це означає, що перевірки прикладу пройшли, а не що весь майбутній помічник готовий.

class Tests(unittest.IsolatedAsyncioTestCase):
    async def test_retry_then_success(self):
        calls = 0
        async def fake(question):
            nonlocal calls
            calls += 1
            if calls == 1:
                raise TransientError('503')
            return 'ok'
        self.assertEqual(await generate(fake, 'q'), 'ok')
        self.assertEqual(calls, 2)
    async def test_permanent_not_retried(self):
        calls = 0
        async def fake(question):
            nonlocal calls
            calls += 1
            raise ValueError('Invalid request')
        with self.assertRaises(ValueError):
            await generate(fake, 'q')
        self.assertEqual(calls, 1)
    async def test_timeout(self):
        async def slow(question):
            await asyncio.sleep(1)
        with self.assertRaises(TransientError):
            await generate(slow, 'q', attempts=1, timeout=0.01)

if __name__ == '__main__':
    unittest.main()

assertEqual перевіряє рівність, assertTrue — істинність умови, assertRaises — очікувану помилку. Якщо перевірка не пройшла, прочитайте очікуване й отримане значення. Помилка на неправильному вводі часто є саме потрібною поведінкою.

Підміна зовнішнього сервісу перевіряє ваш код без мережі. Якість справжньої моделі, роботу зовнішньої бази та швидкість на вашому обладнанні перевіряють окремо. У FastAPI перетворюйте очікувані помилки на зрозумілу відповідь користувачу.

Додайте контроль очікування до помічника. Почніть із підмін, справжній API підключайте за бажанням.

Кроки завдання

  1. Створіть швидку, повільну й помилкову функції.
  2. Поставте максимум 2 спроби й короткий навчальний тайм-аут.
  3. Порахуйте фактичні виклики кожної функції.

Як перевірити свою роботу

Що перевірити кодом

  • Швидка функція повертає результат.
  • Повільна завершується за обмеженим очікуванням.
  • Постійна помилка не запускає повтори.

Що перевірити своїми очима

  • Повідомлення про збій зрозуміле.
  • Відрізняю межу спроби від усього запиту.
  • Ключі не потрапили у звіт.

Як зрозуміти, що завдання виконане
