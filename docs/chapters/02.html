Дані та вектори без складної математики

Після цього розділу ви зможете

Зрозуміти вектор як список чисел, порівняти два прості вектори та помітити неправильні дані.

Вектор — впорядкований список чисел, наприклад [1, 0]. Уявімо дві умовні ознаки документа: мережа й відпустка. [1, 0] позначає мережу, [0, 1] — відпустку. Це вигаданий приклад для розуміння: справжні текстові моделі створюють сотні координат, які не мають таких простих назв.

Вам достатньо базового Python: функцій, списків, словників та винятків. Працюємо над одним помічником для інструкцій команди. Спочатку прочитайте приклад, потім запустіть маленький код, після цього виконайте власне завдання. Незрозуміле слово шукайте на сторінці «Нові слова простими словами».

Як це працює на прикладі

Уявіть вектори як стрілки. Косинусна схожість порівнює напрямки. [1, 0] та [2, 0] дивляться в один бік: результат 1, хоча довжини різні. [1, 0] і [0, 1] перпендикулярні: результат 0. Для текстів це оцінка близькості представлень, а не відсоток правильності відповіді.

Перед обчисленням перевірте однакову довжину списків і скінченність чисел. [0, 0] не має напрямку, тому косинус із ним не визначений. В очищенні таблиць теж не приховуйте помилки: відсутнє значення не завжди можна замінити нулем. Збережіть вихідний файл і причини відхилення рядків.

Нові слова простими словами

Координата
Один елемент списку. У [2, 3] координати 2 та 3.
Розмірність
Кількість координат. [1, 0] має розмірність 2.
Норма
Довжина вектора. Для [3, 4] вона дорівнює √(9+16)=5.
NaN та infinity
Невизначене число й нескінченність. Такі координати наш пошук відхиляє.

Не потрібно завчати визначення. Візьміть одне слово й поясніть його на прикладі нашого помічника. Запишіть у нотатках власне речення. Англійську назву залишено, щоб ви впізнали її в документації.

Розрахунок крок за кроком

Косинус = сума попарних добутків / (довжина першого вектора × довжина другого).

Для [1, 0] і [1, 1]: 1×1 + 0×1 = 1. Довжини 1 та √2 ≈ 1,414. Результат 1 / 1,414 ≈ 0,707. Для [2, 2] результат такий самий, бо напрямок не змінився.

Спробуйте змінити одне число

Повторіть розрахунок на аркуші або в Python. Спочатку передбачте результат, потім перевірте. Важливо розуміти, що саме вимірює число: схожість, правильність, пам’ять чи час. Не всі ці показники можна порівнювати між собою.

Завантажити 02.py — код і перевірки ↓

Збережіть файл у новій папці. Приклад працює на Python 3.12+ зі стандартною бібліотекою, без платних сервісів. Нижче його основна частина; спочатку розберемо, що роблять функції.

"""Run: python 02.py. Standard-library cosine baseline."""
import math
import unittest

def cosine(a, b):
    if not a or len(a) != len(b):
        raise ValueError('Equal nonempty dimensions required')
    if any(not math.isfinite(x) for x in [*a, *b]):
        raise ValueError('Finite coordinates required')
    norm_a = math.sqrt(math.fsum(x*x for x in a))
    norm_b = math.sqrt(math.fsum(x*x for x in b))
    if norm_a == 0 or norm_b == 0:
        raise ValueError('Zero vector')
    return math.fsum(x*y for x, y in zip(a, b)) / norm_a / norm_b

Що тут відбувається

  • math.fsum() додає числа з кращою точністю підсумовування.
  • math.sqrt() обчислює квадратний корінь для довжини.
  • Перевірка нульової норми запобігає діленню на нуль.

Перевірки та обробка помилок

У завантаженому файлі вже є перевірки. Виконайте python 02.py з його папки. Наприкінці має бути OK. Це означає, що перевірки прикладу пройшли, а не що весь майбутній помічник готовий.

class Tests(unittest.TestCase):
    def test_geometry(self):
        self.assertAlmostEqual(cosine([1, 0], [1, 0]), 1)
        self.assertAlmostEqual(cosine([1, 0], [0, 1]), 0)
        self.assertAlmostEqual(cosine([1, 0], [1, 1]), 1/math.sqrt(2))
        self.assertAlmostEqual(cosine([1, 1], [2, 2]), 1)
    def test_bad_vectors(self):
        for a, b in [([], []), ([1], [1, 2]), ([0], [1]), ([math.nan], [1]), ([math.inf], [1])]:
            with self.assertRaises(ValueError):
                cosine(a, b)

if __name__ == '__main__':
    unittest.main()

assertEqual перевіряє рівність, assertTrue — істинність умови, assertRaises — очікувану помилку. Якщо перевірка не пройшла, прочитайте очікуване й отримане значення. Помилка на неправильному вводі часто є саме потрібною поведінкою.

Підміна зовнішнього сервісу перевіряє ваш код без мережі. Якість справжньої моделі, роботу зовнішньої бази та швидкість на вашому обладнанні перевіряють окремо. У FastAPI перетворюйте очікувані помилки на зрозумілу відповідь користувачу.

Як перевірити свою роботу

Що перевірити кодом

  • Однакові вектори дають приблизно 1.
  • Перпендикулярні дають 0.
  • Нульові вектори й різні довжини відхиляються.

Що перевірити своїми очима

  • Розумію різницю напрямку й довжини.
  • Жоден рядок не зник без пояснення.
  • Не називаю схожість точністю відповіді.
