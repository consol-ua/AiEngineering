Модель на власному комп’ютері

Після цього розділу ви зможете

Оцінити ресурси для моделі й за можливості спробувати локальну відповідь.

Локальна модель працює на вашому комп’ютері замість зовнішнього API. Ви контролюєте середовище, але самі забезпечуєте пам’ять і швидкість. Почніть із невеликої моделі. Завантажений файл ще не означає, що генерація поміститься в пам’ять і буде зручною.

Вам достатньо базового Python: функцій, списків, словників та винятків. Працюємо над одним помічником для інструкцій команди. Спочатку прочитайте приклад, потім запустіть маленький код, після цього виконайте власне завдання. Незрозуміле слово шукайте на сторінці «Нові слова простими словами».

Як це працює на прикладі

Параметри моделі — числа, що зберігають результат навчання. Квантизація зберігає їх із меншою точністю, наприклад у 4 бітах замість 16. Розмір зменшується, але якість і швидкість можуть змінитися. Пам’ять також потрібна для контексту та роботи програми, не лише параметрів.

Ollama й llama.cpp — програми запуску моделей. Оберіть instruct-модель, пристосовану до інструкцій, і перевірте мови, ліцензію та формат. Якщо ресурсів не вистачає, здайте розрахунок і пояснення. Не називайте живий запуск перевіреним, якщо він не виконувався.

Нові слова простими словами

Параметри
Числа всередині моделі. 1B — приблизно мільярд параметрів.
Квантизація
Менше бітів на число: файл менший, але результат може змінитися.
Inference
Отримання відповіді вже навченої моделі, не навчання заново.
TTFT
Time to first token — час до першої частини відповіді. Повний текст з’явиться пізніше.

Не потрібно завчати визначення. Візьміть одне слово й поясніть його на прикладі нашого помічника. Запишіть у нотатках власне речення. Англійську назву залишено, щоб ви впізнали її в документації.

Розрахунок крок за кроком

Мінімум байтів для параметрів ≈ параметри × біти / 8.

1 мільярд параметрів у 4 бітах: 1 000 000 000 × 4 / 8 = 500 000 000 байтів, близько 0,5 GB. Це лише нижня межа параметрів. Контекст, обчислення й операційна система потребують додаткової RAM.

Спробуйте змінити одне число

Повторіть розрахунок на аркуші або в Python. Спочатку передбачте результат, потім перевірте. Важливо розуміти, що саме вимірює число: схожість, правильність, пам’ять чи час. Не всі ці показники можна порівнювати між собою.

Завантажити 13.py — код і перевірки ↓

Збережіть файл у новій папці. Приклад працює на Python 3.12+ зі стандартною бібліотекою, без платних сервісів. Нижче його основна частина; спочатку розберемо, що роблять функції.

"""Run: python 13.py. Lower bound only, not full memory requirement."""
import math
import unittest

def weight_bytes(parameters, bits):
    if type(parameters) is not int or parameters <= 0 or type(bits) is not int or bits <= 0:
        raise ValueError('Positive integer parameters and bits required')
    return math.ceil(parameters * bits / 8)

def sizing(parameters, bits, available_bytes):
    weights = weight_bytes(parameters, bits)
    return {'weight_lower_bound': weights, 'available': available_bytes,
            'weights_fit': weights <= available_bytes,
            'runtime_readiness': 'unverified: KV, activations and runtime not measured'}

Що тут відбувається

  • weight_bytes() лише рахує параметри.
  • True у weights_fit не доводить готовність: runtime_readiness прямо каже unverified — не перевірено.
  • Код не завантажує модель і не виконує генерацію.

Маленький запуск із відомим результатом

Створіть demo.py у тій самій папці, де лежить 13.py. Скопіюйте наступний код і виконайте python demo.py. runpy.run_path() завантажує функції зі збереженого файла; ви не повинні переписувати їх вручну.

import runpy
m = runpy.run_path("13.py")
print(m["weight_bytes"](1_000_000_000, 4))
print(m["sizing"](1_000_000_000, 4, 2_000_000_000)["weights_fit"])

Перевірки та обробка помилок

У завантаженому файлі вже є перевірки. Виконайте python 13.py з його папки. Наприкінці має бути OK. Це означає, що перевірки прикладу пройшли, а не що весь майбутній помічник готовий.

class Tests(unittest.TestCase):
    def test_lower_bound(self):
        self.assertEqual(weight_bytes(1_000_000_000, 4), 500_000_000)
        self.assertEqual(weight_bytes(1_000_000_000, 16), 2_000_000_000)
        self.assertIn('unverified', sizing(1000, 4, 10000)['runtime_readiness'])
    def test_invalid(self):
        for parameters, bits in [(0, 4), (-1, 4), (10, 0), (True, 4)]:
            with self.assertRaises(ValueError):
                weight_bytes(parameters, bits)

if __name__ == '__main__':
    unittest.main()

assertEqual перевіряє рівність, assertTrue — істинність умови, assertRaises — очікувану помилку. Якщо перевірка не пройшла, прочитайте очікуване й отримане значення. Помилка на неправильному вводі часто є саме потрібною поведінкою.

Підміна зовнішнього сервісу перевіряє ваш код без мережі. Якість справжньої моделі, роботу зовнішньої бази та швидкість на вашому обладнанні перевіряють окремо. У FastAPI перетворюйте очікувані помилки на зрозумілу відповідь користувачу.

Практика: зробіть самостійно

Підготуйте план локального запуску й за можливості виконайте його.

Кроки завдання

  1. Запишіть CPU, RAM і наявність GPU.
  2. Оберіть невелику instruct-модель із потрібною мовою.
  3. Порахуйте нижню межу та залиште запас.
  4. За документацією Ollama або llama.cpp виконайте локальний запуск.
  5. Перевірте 5 питань, час першого тексту та повної відповіді.
  6. Якщо запуск недоступний, покажіть розрахунок і незапущені перевірки.

Що показати після виконання

  • Опис комп’ютера й моделі.
  • Розрахунок пам’яті.
  • Результати або конкретна причина відсутнього запуску.
Почніть із мінімального варіанта. Частини з позначкою «додатково» не потрібні для першого успіху. Якщо зовнішня модель чи обладнання недоступні, виконайте незалежні кроки й запишіть, що саме ще не перевіряли.

Як перевірити свою роботу

Що перевірити кодом

  • 1B і 4 біти дають 500 000 000 байтів.
  • Неправильні параметри відхиляються.
  • Розрахунок не оголошує повну готовність.

Що перевірити своїми очима

  • Запас пам’яті залишений.
  • Запущені відповіді прочитані вручну.
  • Незапущені частини явно позначені.
