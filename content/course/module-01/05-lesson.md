## Урок 5. Типи мовних моделей

### 5.1. Base Models vs Instruct Models

Base model навчається передбачати продовження тексту. Вона може добре моделювати мову, але не обов'язково надійно виконуватиме інструкції користувача.

Instruct model проходить додаткове навчання для виконання інструкцій і ведення діалогу. Воно може включати supervised fine-tuning та різні методи preference optimization.

Для AI-асистента зазвичай варто починати з instruct-моделі.

### 5.2. Encoder, Decoder та Encoder-Decoder

| Архітектура     | Типове використання                        |
| --------------- | ------------------------------------------ |
| Encoder-only    | Класифікація, embeddings, розуміння тексту |
| Decoder-only    | Генерація тексту, чат, tool calling        |
| Encoder-decoder | Переклад, підсумовування, text-to-text     |

Ці категорії описують архітектуру, але конкретні можливості залежать від навчання моделі.

### 5.3. Open-weight vs Hosted Models

Open-weight models дозволяють отримати ваги моделі відповідно до умов її ліцензії. Це не завжди означає повністю open-source модель.

Hosted models доступні через API провайдера, який керує інфраструктурою inference.

| Критерій                | Локальна модель           | Hosted API                      |
| ----------------------- | ------------------------- | ------------------------------- |
| Початкове налаштування  | Складніше                 | Простіше                        |
| Контроль інфраструктури | Вищий                     | Нижчий                          |
| Масштабування           | Власна відповідальність   | Значною мірою провайдера        |
| Витрати                 | Обчислювальні ресурси     | Тарифікація сервісу             |
| Приватність             | Залежить від конфігурації | Залежить від політик провайдера |
| Оновлення моделі        | Під твоїм контролем       | Може залежати від провайдера    |
