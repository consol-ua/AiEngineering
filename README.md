# GitHub Pages — браузерна версія

Гілка `github-pages` містить готовий статичний сайт у `docs/`. Серверна версія з FastAPI залишається в `main`; її файли також збережено в цій гілці, але GitHub Pages публікує лише `docs/`.

## Увімкнути безкоштовний хостинг

У репозиторії відкрийте **Settings → Pages → Build and deployment**:

- Source: **Deploy from a branch**.
- Branch: **github-pages**.
- Folder: **/docs**.
- Натисніть **Save** та дочекайтеся успішної публікації.

Очікувана адреса після публікації: https://consol-ua.github.io/AiEngineering/

## Розгорнуті навчальні розділи

Кожен із 16 модулів має окремий reader у `docs/chapters/01.html` … `16.html`: 12 навчальних сторінок (модулі 1–2 — по 18, модуль 3 — 18) зі змістом, кнопками навігації, режимом усього розділу та «Друк / PDF». Відкрийте модуль на головній сторінці та натисніть «Читати повний розділ».

Структура: постановка задачі, механізми, термінологія, формули з розрахунками, архітектура/SVG, best practices, антипатерни, реалізація, тести й помилки, лабораторна, evaluation, джерела й відео. Задано розриви сторінок для друку: перевірено 12 A4-сторінок у Chromium з полями 16 mm і 11 pt. Інші шрифти та налаштування друку можуть змінити кількість. Це 12 окремих навчальних сторінок, а не оцінка кількості стандартних книжкових сторінок за словами.

Нотатки та чотири відмітки розділу використовують попереднє браузерне сховище; резервні копії залишаються сумісними. Нових кроків прогресу не додається: як і раніше, у курсі 64 кроки.

Виконувані Python 3.12+ приклади з негативними тестами: `docs/examples/01.py` … `16.py`; усі можна завантажити ZIP із головної сторінки. Приклади стандартної бібліотеки перевіряють окремі компоненти без API-ключів. Вони не підміняють лабораторні з реальними embeddings, моделями, Docker та навантаженням. Live-перевірки виконуються студентом окремо. Посилання документацій і відео не перевірялися на актуальну доступність; відео з позначкою «Пошук» — тематична видача YouTube.

## Прогрес та резервні копії

Нотатки доступні всередині кожного з 16 модулів (до 20 000 символів). Вони зберігаються одразу під час введення; повідомлення під полем підтверджує збереження або показує помилку.

Виконані кроки та нотатки автоматично зберігаються у `localStorage` цього браузера. Облікові записи не потрібні. Інші пристрої, профілі браузера або інша адреса сайту мають окремий прогрес. Приватний режим та очищення даних можуть видалити результати.

«Резервна копія» → «Експортувати JSON» завантажує файл із 64 кроками прогресу, версією формату, датою та нотатками. Старі копії версії 1 без нотаток залишаються сумісними. На іншому пристрої виберіть файл і натисніть «Імпортувати й об’єднати»: виконані кроки додаються до поточних. Різні нотатки одного модуля об’єднуються з роздільником; однакові не дублюються, порожні не стирають наявний текст. Некоректні файли відхиляються без зміни даних. Оновлення з іншої вкладки синхронізуються автоматично.

Попередній прогрес із серверної SQLite не переноситься автоматично. У браузерній версії немає автоматичних Telegram-нагадувань; вони потребують серверної версії. Токени чи паролі у статичний сайт не додавайте.

## Локальна перевірка

```bash
python -m http.server 8080 --directory docs
```

Для браузерного smoke-тесту встановіть Playwright та Chromium у вашому середовищі:

```bash
python -m pip install playwright
python -m playwright install chromium
python tests/pages_smoke.py
# Або використайте вже встановлений Chromium:
CHROMIUM_PATH=/usr/bin/chromium python tests/pages_smoke.py
```

Тест перевіряє збереження після перезавантаження, експорт/імпорт, відхилення неправильних файлів, синхронізацію вкладок, мобільну ширину та відсутність API-запитів.

# AI Atelier

Навчальний сайт українською: 16 тижнів AI Engineering для розробника Python/FastAPI, 64 кроки, SVG-схеми, приклади коду, безкоштовні статті та тематичний пошук YouTube. Програма адаптована з доступних вимог; повний текст згаданої розмови недоступний.

## Запуск

```bash
cd /workspace/AiEngineering
python -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/uvicorn app:app --host 0.0.0.0 --port 8000
```

Відкрийте сервер через доступний у вашій платформі механізм доступу. Дані за замовчуванням зберігаються у `learning.sqlite3`; налаштуйте `DATABASE_PATH` для постійного тому та резервного копіювання. SQLite містить облікові записи, хеші паролів, сесії, прогрес і налаштування Telegram. Паролі: PBKDF2 SHA-256 із випадковою сіллю; cookie HttpOnly, SameSite Strict, термін 30 діб.

## Telegram

1. Створіть бота через @BotFather.
2. Безпечно задайте серверну змінну `TELEGRAM_BOT_TOKEN`. Не комітьте токен.
3. Надішліть боту `/start`; отримайте свій числовий Chat ID через Telegram API `getUpdates` (не публікуйте URL із токеном).
4. Увійдіть на сайт → «Нагадування» → збережіть Chat ID та час → «Надіслати тест».

Нагадування щоденні, за Europe/Kyiv, лише коли сервер працює. Запускайте **один worker**, щоб уникнути дублювання. Пропущені під час простою повідомлення не надсилаються заднім числом. Без токена сайт і прогрес працюють; фактичне надсилання потребує доступу до api.telegram.org. Помилки надсилання не розкривають токен у відповіді або логах.

## Межі поточної версії

Проста авторизація для невеликого особистого/навчального сервісу. Перед публічним запуском додайте HTTPS, `COOKIE_SECURE=1`, rate limiting, відновлення пароля, контроль реєстрації та моніторинг помилок нагадувань. Шрифти завантажуються з Google Fonts з системним fallback. Посилання на відео — пошук за темою, не перевірені конкретні ролики. Окремі практичні роботи з LLM можуть потребувати завантаження моделей або платного API; сайт сам не викликає LLM.
